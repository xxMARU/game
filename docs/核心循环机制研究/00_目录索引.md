## 核心发现概览

### 独立游戏12款的共性规律

1. **低摩擦重开**：所有高留存独立游戏的死亡→重开时间均<15秒
2. **高密度微决策**：每10秒窗口内都有一个值得做的有意义选择
3. **操作复杂度与反馈密度反比**：操作越简单的游戏，感官反馈越密集
4. **死亡惩罚与重试频率反比**：死亡越频繁，惩罚越轻
5. **97%+好评率共性**：都将核心难度与"不惩罚放弃"的安全网结合

### 网游11款的核心设计模式

| 模式 | 代表游戏 | 核心原理 |
|------|---------|---------|
| 竞技弹性周历 | WoW、LoL | 补丁改Meta注入可变性，成本极低 |
| 尊重离开 | FFXIV | 允许玩家走，但保证有理由回来 |
| 体力经济学 | 原神、王者荣耀 | 损失厌恶驱动日活，碎片时间适配 |
| 赛季重置乘数 | PoE、Fortnite | 经济/段位重置让同一内容反复卖新鲜感 |
| 涌现式目标 | Minecraft、Terraria | 系统涌现性足够高时玩家自造内容 |
| 社交仪式化 | LoL、Destiny 2 | 游戏行为变社交仪式=社会惯性留存 |

## 使用建议

1. **新项目立项**：先读05（方法论）确定核心循环框架，再对标01-04中同类型案例
2. **系统设计优化**：找到与自己项目最相似的2-3个案例，对比各层循环参数
3. **运营诊断**：使用05中的诊断清单检查核心循环健康度
4. **商业化设计**：参考05中付费点嵌入位置的分析框架
