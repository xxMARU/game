# 08 永久进度与Meta循环设计方法论

> 版本: v1.0 | 最后更新: 2026-03-29
> 定位: 跨Session永久进度系统与Meta Game层设计的完整框架

---

## 1. 核心理念

永久进度（Permanent Progression）是连接单局体验与长期留存的桥梁。它回答一个根本问题：**"为什么我明天还要回来？"**

```
长期留存 = f(永久进度感知速度, 内容解锁深度, 操作技能天花板)
```

**Meta循环**是嵌套在核心循环之外的更大循环——如果核心循环是"一局"的体验，Meta循环就是"一百局"的体验弧线。

## 2. 永久进度四种类型

### 2.1 类型总览

| 类型 | 定义 | 核心感受 | 典型品类 | 风险 |
|------|------|---------|---------|------|
| **数值型** | 角色属性/等级永久提升 | "我变强了" | RPG/MMO/ARPG | 数值膨胀/Pay-to-Win |
| **解锁型** | 新内容/能力/选项永久开放 | "我有了新选择" | Roguelike/平台/沙盒 | 解锁完=内容枯竭 |
| **知识型** | 玩家个人技能/认知提升 | "我变厉害了" | Souls-like/格斗/竞技 | 难以量化/难以满足收集欲 |
| **赛季重置型** | 定期重置部分进度，保留核心 | "新的开始+继承" | Live Service/竞技/ARPG | 重置过多=沮丧 |

### 2.2 数值型永久进度参数

```
属性增长模型:
├── 线性增长: Stat(n) = Base + k × Level
│   适用: 早期阶段，玩家直觉理解
│   风险: 后期增长无感
│
├── 递减增长: Stat(n) = Base + k × Level^0.7
│   适用: 主流RPG，维持成长感同时控制膨胀
│   推荐: 多数场景
│
├── 阶梯增长: 每N级一次突破性提升
│   适用: 配合里程碑解锁（如进化/转职）
│   效果: 制造"突破感"峰值
│
└── S曲线增长: 早期慢→中期快→后期慢
    适用: 有明确"毕业"概念的系统
    效果: 中期最爽，后期自然引向赛季重置
```

**关键参数:**
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 满级所需时间 | 40-100小时(主线) | 太短=内容不足，太长=流失 |
| 每小时等级提升感知 | 至少1次"变强感知事件" | 可以是等级/装备/技能 |
| 数值膨胀比(终/初) | 5-20倍(PvE) / 1.5-3倍(PvP) | PvP必须控制膨胀 |

### 2.3 解锁型永久进度参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 首小时解锁速度 | 每10-15分钟一个新内容 | Hook阶段密集解锁 |
| 总解锁物数量 | 50-300+(含装饰) | 少于30个=后期空虚 |
| 游戏性解锁 vs 装饰解锁 | 30:70 | 游戏性解锁太多=必要感过强 |
| 解锁后使用率 | 目标>30%的解锁物有人用 | 太低=解锁无意义 |

### 2.4 知识型永久进度参数

| 参数 | 设计要点 | 案例 |
|------|---------|------|
| 技能天花板 | 理论无限但有可感知的里程碑 | 格斗游戏段位/Speedrun记录 |
| 进步可见性 | 必须有外化指标 | Celeste死亡计数/Boss击杀时间 |
| 社区验证 | 技能需要社交认同 | 排行榜/回放分享/PvP段位 |

### 2.5 赛季重置型参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 赛季周期 | 8-13周(主流) | 太短=压力，太长=倦怠 |
| 保留比例 | 永久保留40-60%的进度 | 具体见下节重置矩阵 |
| 新内容量 | 每赛季20-30%新内容 | 低于15%=换皮感 |

## 3. 永久进度黄金比例

### 3.1 "永久进度解决多少%难度"

**核心发现:** 在优秀的进度系统中，永久进度（数值/装备/解锁）应解决总难度的**15-30个百分点**，而玩家操作技能应贡献**40-55个百分点**。

```
难度克服构成:
├── 玩家操作技能:   40-55%  ← 核心体验感
├── 永久进度(数值): 15-30%  ← 成长回报感
├── 局内随机/选择:  10-20%  ← Build多样性
└── 社交/信息:       5-15%  ← 社区价值

总计 = 100% (通关/通关当前最高难度)
```

**为什么是15-30%而非更高:**
- **>30%**: 进度成为"氪金捷径"，操作无关紧要 → P2W感知
- **<15%**: 进度感微弱，"我升级了但好像没变化" → 投资感缺失
- **40-55%操作**: 保证"是我在变强，不是数字在变大"的核心体验

### 3.2 不同品类的比例校准

| 品类 | 操作% | 进度% | 局内RNG% | 社交% |
|------|-------|-------|---------|-------|
| Roguelike(Hades) | 45% | 20% | 25% | 10% |
| Souls-like | 55% | 20% | 5% | 20%(知识共享) |
| MOBA(排位) | 50% | 0% | 15%(选英雄) | 35%(团队) |
| MMO(PvE) | 30% | 40% | 10% | 20% |
| 自走棋 | 35% | 0% | 45% | 20% |
| 休闲三消 | 20% | 25% | 30% | 25% |

## 4. 解锁节奏五阶段模板

### 4.1 五阶段概览

```
解锁密度
  高 │  ████
     │  ████ █████
     │  ████ █████  ████
  中 │  ████ █████  ████   ████
     │  ████ █████  ████   ████    █
  低 │──────────────────────────────────→ 游戏时间
     │ HOOK  扩展   深化   精通   完美
     │ 0-2h  2-15h  15-50h 50-150h 150h+
```

### 4.2 各阶段详细参数

| 阶段 | 时间窗口 | 解锁频率 | 解锁类型 | 目标情感 | 设计要点 |
|------|---------|---------|---------|---------|---------|
| **Hook** | 0-2小时 | 每5-10分钟 | 核心机制/首批角色/基础系统 | "好多新东西！" | 密集但不压倒 |
| **扩展** | 2-15小时 | 每20-40分钟 | 新模式/新区域/进阶系统 | "原来还有这些" | 逐层揭示深度 |
| **深化** | 15-50小时 | 每1-2小时 | 高级Build/稀有装备/隐藏内容 | "我越来越懂了" | 组合复杂度提升 |
| **精通** | 50-150小时 | 每3-5小时 | 终局内容/挑战模式/传说装备 | "我是专家了" | 难度驱动而非密度驱动 |
| **完美** | 150小时+ | 每10-30小时 | 收藏品/成就/排行榜/装饰 | "我要100%" | 自驱动，非必要 |

### 4.3 各阶段案例对照

| 阶段 | Hades | 原神 | Dead Cells |
|------|-------|------|-----------|
| Hook | 前3个武器+镜子系统 | 风神瞳+元素反应+前4角色 | 前3个武器蓝图+突变 |
| 扩展 | 6个武器全解锁+恩赐系统 | 7国探索+深渊+角色池扩展 | Boss Cell 1-2+更多蓝图 |
| 深化 | 武器形态+恩赐组合+暗月 | 圣遗物/天赋/深渊36星挑战 | Boss Cell 3-4+锻造升级 |
| 精通 | 高热度通关+速通 | 渊下宫/大世界100%/深渊满星 | Boss Cell 5+全蓝图 |
| 完美 | 全鱼/全预言/全关系满 | 全成就/全家具/限定收集 | 全成就+挑战模式 |

## 5. 赛季重置决策矩阵

### 5.1 保留 vs 重置什么

| 系统 | 保留(推荐) | 重置(推荐) | 说明 |
|------|-----------|-----------|------|
| **角色等级** | ✅ 保留基础等级 | ⚠ 可选Paragon重置 | 重置等级极度不受欢迎 |
| **核心装备** | ✅ 保留已获取装备 | ❌ 不要删装备 | 装备=情感投资 |
| **赛季货币** | ⚠ 部分转化保留 | ✅ 赛季专属货币重置 | 1:10比例转化为通用货币 |
| **排位段位** | ⚠ 软重置(降2-4级) | ✅ 硬数据重置 | 软重置>硬重置(减少挫败) |
| **赛季通行证** | ❌ 本赛季结束 | ✅ 新通行证替代 | 奖励永久保留 |
| **收藏/装饰品** | ✅ 永久保留 | ❌ 永远不重置 | 这是玩家"存在证明" |
| **赛季独占内容** | ✅ 已获取的保留 | ✅ 未获取的移除 | FOMO但已拥有=安全 |
| **图鉴/成就** | ✅ 永久保留 | ❌ 不重置 | 知识型进度不可逆 |
| **技能树/天赋** | ⚠ 视品类而定 | ✅ 赛季Build重选 | Path of Exile式重选有新鲜感 |
| **社交关系** | ✅ 永久保留 | ❌ 绝不重置 | 社交是最强留存因子 |

### 5.2 重置强度分级

| 等级 | 名称 | 保留比例 | 适用品类 | 案例 |
|------|------|---------|---------|------|
| 1 | 软重置 | 保留80-90% | 竞技/排位 | LoL赛季段位软重置 |
| 2 | 中度重置 | 保留50-70% | ARPG赛季 | Diablo赛季(角色转非赛季) |
| 3 | 强重置 | 保留20-40% | 生存/BR赛季 | Rust强制wipe |
| 4 | 全重置 | 保留<10% | Roguelike/赛季重启 | Path of Exile新赛季 |

### 5.3 赛季时间线模板

```
Week 0:    赛季开始 → 新内容集中释放 → 回归峰值
Week 1-2:  蜜月期 → 新Build探索 → DAU最高点
Week 3-5:  深化期 → 排行榜竞争 → 核心玩家粘性最强
Week 6-8:  稳定期 → 中期活动/补丁 → 维持活跃
Week 9-10: 衰退期 → 通行证冲刺 → FOMO驱动
Week 11-12: 预热期 → 下赛季预告/PTR → 回归期待
Week 13:   赛季结束 → 重置 → 循环
```

## 6. 日常/周常系统黄金比例

### 6.1 核心公式

```
日常任务时间 ≤ 玩家总游戏时间的 33%
日常任务奖励 = 每日总收入的 40-55%
```

### 6.2 参数详解

| 参数 | 推荐值 | 超标后果 | 说明 |
|------|--------|---------|------|
| **日常任务数量** | 3-5个 | >5个=义务感，<3个=不够引导 | 3个核心+2个可选 |
| **日常完成时间** | 15-25分钟 | >30分钟=日常即游戏全部 | 目标玩家还有时间自由玩 |
| **日常奖励占比** | 40-55%日收入 | >60%=必须做日常才能进步 | 给非日常活动留足奖励空间 |
| **周常任务数量** | 5-8个 | >10个=一周都在做作业 | 跨越多个系统 |
| **周常完成时间** | 2-4小时/周 | >6小时=周常即全部内容 | 分散在多天完成 |
| **周常奖励占比** | 周收入的25-35% | >40%=周一不做周常焦虑 | 大块奖励（如高级材料/抽卡资源） |

### 6.3 日常系统设计原则

1. **不要惩罚缺勤** — 错过一天日常不应产生不可弥补的损失
2. **追赶机制** — 休息3天后回来应有加速追赶手段
3. **品质>数量** — 3个有趣的日常 >> 10个重复的日常
4. **变化的日常** — 从任务池随机抽取，而非每天完全相同
5. **自然融合** — 日常目标应引导玩家做本来就想做的事
6. **明确结束** — 完成日常后应清晰告知"今天的已做完"

### 6.4 反面案例警示

| 游戏 | 问题 | 后果 |
|------|------|------|
| 魔兽世界(BfA) | 艾泽里特能量日常过于必要 | 不做=进度严重落后，玩家怨声载道 |
| 原神(早期) | 日常=树脂=唯一成长路径 | 日常之外无事可做→快速倦怠 |
| Destiny 2(多赛季) | 弹力源/赛季周常叠加过多 | "作业感"成为社区核心抱怨 |

## 7. 综合设计决策流程图

```
步骤1: 确定永久进度类型组合
  │
  │  Q: 游戏的核心吸引力是什么?
  │  ├─ 数值成长感 → 数值型为主 (RPG/MMO)
  │  ├─ 内容探索 → 解锁型为主 (Roguelike/冒险)
  │  ├─ 技术精进 → 知识型为主 (格斗/竞技)
  │  └─ 持续新鲜感 → 赛季重置型为主 (Live Service)
  │  注: 多数游戏是2-3种混合
  │
  ▼
步骤2: 设定黄金比例
  │
  │  永久进度解决难度%: 15-30%
  │  操作技能贡献%: 40-55%
  │  局内变量%: 10-20%
  │  社交因子%: 5-15%
  │  → 校验总和=100%
  │
  ▼
步骤3: 规划解锁节奏五阶段
  │
  │  Hook(0-2h): 每5-10分钟解锁
  │  扩展(2-15h): 每20-40分钟解锁
  │  深化(15-50h): 每1-2小时解锁
  │  精通(50-150h): 每3-5小时解锁
  │  完美(150h+): 自驱动
  │  → 内容总量是否支撑各阶段?
  │
  ▼
步骤4: 设计日常/周常/赛季系统
  │
  │  日常: ≤33%时间, 40-55%日收入
  │  周常: 2-4小时/周, 25-35%周收入
  │  赛季: 8-13周周期, 保留40-60%进度
  │  → 是否有追赶机制?
  │  → 缺勤惩罚是否可接受?
  │
  ▼
步骤5: 压力测试与验证
  │
  │  ├─ 模拟「每天30分钟」玩家: 能否有意义地推进?
  │  ├─ 模拟「每周20小时」核心玩家: 是否有足够深度?
  │  ├─ 模拟「离开1个月回归」玩家: 追赶成本可接受?
  │  ├─ 检查P2W风险: 付费能跳过多少操作比例?
  │  └─ 赛季重置后: D1回归动力是否足够?
```
