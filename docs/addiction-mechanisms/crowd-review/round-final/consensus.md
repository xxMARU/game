## 一、系统定位（一句话）

> **本系统是一个"数据稀缺场景的数值预飞行检查器"——在缺乏真人行为数据的游戏开发场景中，使用计算行为学Agent模型对参数化的休闲手游设计空间进行预筛选，输出"值得投入真人测试资源去验证的候选参数配置"。系统输出是假设清单，不是设计方案。**

### 适用/不适用场景

| 场景 | 适用？ | 理由 |
|------|--------|------|
| 新游戏立项（无历史数据） | **核心场景** | 唯一可用的预筛方法 |
| 现有游戏引入全新机制 | **重要场景** | 历史数据不可直接迁移 |
| 跨品类/跨市场迁移 | **补充场景** | 数据可迁移性低 |
| 成熟游戏日常运营调优 | **不适用** | 大厂数据驱动方法更优 |
| 付费/社交/视听设计优化 | **不适用** | 超出系统覆盖范围 |
| 独立开发者自建系统 | **不推荐** | ROI负值；推荐使用SaaS版 |

### 目标客户

30-200人的中小型游戏工作室，年立项2-5款休闲游戏，缺少专业数据分析团队。

## 四、适应度函数（最终版公式）

### Phase 0（简化版）

```
fitness_v0 = median_session_value(agent_group, design_config)

其中：session_value = session_length × exp(-session_length / τ)
τ = 40（Agent步数单位，Phase 0时间映射标定后修正）
```

### Phase 1（完整版）

```
fitness = session_value_norm^0.40 × robustness^0.20 × safety^0.25 × novelty^0.15

其中：
  session_value = session_length × exp(-session_length / τ)
  session_value_norm = minmax_normalize(session_value, [0.1, 1.0])
  robustness = minmax_normalize(agent_type_agreement × parameter_stability, [0.1, 1.0])
  safety = sigmoid_clip(1 - exploit_penalty) × psd_coherence
  novelty = 1 + 0.2 × distance_to_archive(design, historical_archive)

权重：w1=0.40, w2=0.20, w3=0.25, w4=0.15 (Σ=1.0)
组合方式：加权几何平均 ∏(factor_i ^ w_i)
下限截断：各因子≥0.1（sigmoid软截断，保持低分区梯度）
```

**各因子定义**：

| 因子 | 定义 | 目的 |
|------|------|------|
| session_value | sl × exp(-sl/τ)，倒U型映射 | 会话不是越长越好，有最优点 |
| agent_type_agreement | 加权Kendall τ，各算法按人口代表性赋权 | 跨模型一致性 |
| parameter_stability | Top参数±10%扰动后fitness变化幅度的负值 | 鲁棒性 |
| psd_coherence | 微扰方向一致性+效应存在性 | 检测假高分 |
| exploit_penalty | action_diversity + state_coverage + reward_variance + quit_distribution连续评分 | 反作弊 |
| novelty_bonus | 行为指纹距离到历史档案库 | 防过早收敛 |

**engagement_ratio在Phase 1的处理**：
- 正常计算并记录
- <0.3标注⚠️"参与质量待验证"
- 低engagement_ratio设计**不进入CMA-ES精英集**
- **不淘汰、不删除**——保留在档案中供Phase 2回溯验证

**双fitness交叉验证**：
- fitness_primary（上述加权几何平均）→ 用于CMA-ES进化选择
- fitness_secondary（纯中位数session_value排名）→ 用于独立验证
- 两套Top 10重叠度<50%时触发警报 → 人工审查因子权重

### Phase 2（扩展版）

在Phase 1基础上新增：
- `multi_session_score`：7天模拟总参与时长
- `vulnerability_score`：脆弱群体Agent的成瘾风险（惩罚项）
- `cultural_robustness`：跨文化Agent群组间一致性
- engagement_ratio：根据效度验证结果决定是否恢复为过滤器/连续变量

## 七、Go/No-Go门控（每个Phase的精确标准）

### Phase 0 → Phase 1

**必须全部通过（AND逻辑）**：

| # | 标准 | 度量 | 阈值 | 不通过后果 |
|---|------|------|------|-----------|
| G0-1 | Agent区分好/差设计 | Cohen's d | >0.5 | **项目终止或根本性重设计** |
| G0-2 | Agent排序与金标准一致 | 好/差排序一致Agent比例 | ≥80% | **项目终止或根本性重设计** |
| G0-3 | 会话时长分布合理 | Kolmogorov-Smirnov检验 | p>0.05 | 回退修复退出模型，重试1次 |
| G0-4 | 计算可行性 | 单轮迭代时间 | ≤4小时（单机） | 引入并行化或缩减Agent |
| G0-5 | 时间预算 | Phase 0总耗时 | ≤8周 | 评估范围，决定继续或终止 |
| G0-6 | 退出模型超参数稳定性 | 排序翻转率（27组拉丁超立方） | ≤30% | 重设计先验分布，重试1次 |
| G0-7 | 效应量置信区间 | Cohen's d的95% bootstrap CI下界 | >0.3 | 增加Agent数量后重测 |
