## 1. 系统定位（修正后）

> **本系统是一个"计算行为学筛选工具"（Computational Behavioral Screening Tool）——使用受计算神经科学启发的Agent模型，在参数化的游戏设计空间中搜索"使模拟行为模型产生长且健康会话"的参数配置，作为"可能也使真实人类产生长且健康会话"的候选集。系统输出是假设，不是结论；是候选，不是推荐。产品化名称建议："数值预飞行检查器"（Numerical Pre-flight Checker）。**

**相对R1的变更**：
- R1定位："给定一款已有核心玩法的休闲手游，在其数值参数空间内搜索高参与度配置的辅助筛选工具"
- R2修正：增加了认识论定位（"假设不是结论"——来自E）、增加了产品化名称（"数值预飞行检查器"——来自A）、增加了"健康"限定词（"长且健康的会话"——综合C和E的关切）
- **变更理由**：E系统性论证了代理忠实度问题（Agent行为指标≠人类主观体验），R2共识必须在定位层面就设定正确的认识论期望

## 2. 核心架构决策更新

以下仅列出**相对R1有变更**的决策。R1中未列出的决策维持R1原判。

### 决策2.3-修正：心理特质选择
**Phase 0仍为3种（损失厌恶、延迟折扣、疲劳），但损失厌恶参数校正。**
- 损失厌恶λ均值：R1=2.5（LogNormal分布）→ **R2=1.8，范围[1.2, 3.0]**
- **变更理由**：C论证游戏内虚拟进度的心理价值远低于货币，2.5来自Kahneman的赌博实验，在非货币场景下偏高。参考Ert & Erev (2013)在小额非货币决策中的估计。
- Phase 1扩展到5种（+好奇心、沉没成本）——**维持R1不变**
- **新增Phase 1要求**：追踪并记录Agent决策entropy随时间的变化（为Phase 2评估习惯/自动化机制的必要性提供数据支撑），但Phase 1不将entropy接入退出模型

### 决策2.7-修正：因果干预+超参数敏感性
**R1的HSCD方案维持不变，新增超参数敏感性扫描要求。**
- **新增G0标准（G0-6）**：Phase 0必须对退出模型3个核心参数（frustration_threshold、boredom_rate、poisson_lambda）做27组拉丁超立方采样，确认设计排序对先验分布选择的稳定性
- 如果排序翻转超过30%，退出模型需要重新设计
- **变更理由**：B指出系统有30-40个超参数，退出模型参数的先验选择直接决定session_length分布形态，是可复现性的关键威胁

### 决策2.11（新增）：进化优化器选择
**Phase 1采用CMA-ES替代传统GA。**
- 理由：B论证8维连续参数空间正是CMA-ES最优适用范围，自动学习参数相关性，收敛速度优于GA
- 30%随机探索配额通过CMA-ES种群与随机采样的混合实现
- 推荐实现：`pycma`库
- **这是R1未涉及的新决策**

### 决策2.12（新增）：产品输出格式
**Phase 0必须同步设计输出格式原型。**
- 最小输出格式：推荐配置方案 + 预期影响范围 + 置信度 + 风险提示
- 所有输出附带认识论置信度标签（行为统计/机制假设/迁移预测三级）
- **变更理由**：A指出策划不会读Agent行为统计向量；E要求认识论标签防止过度解读

### 决策2.13（新增）：市场风险纳入
**风险清单补充3项市场风险。**
- MR1：竞品先发（Unity Adaptive Game Tuning）——概率0.5，影响0.8，风险值0.40
- MR2：开源替代——概率0.4，影响0.6，风险值0.24
- MR3：监管收紧导致赛道归零——概率0.2，影响0.9，风险值0.18
- MR1进入Top 3风险（风险值0.40，仅次于R2的Reward Hacking 0.42）
- **变更理由**：D系统性论证R1风险清单完全缺失市场维度，这是结构性遗漏

## 4. 适应度函数更新

### 4.1 Phase 0 适应度——无变化
```
fitness_v0 = median_session_length(agent_group, design_config)
```

### 4.2 Phase 1 适应度——结构性变更

```
fitness = session_length_norm^0.4 × robustness^0.25 × safety^0.25 × novelty^0.15

⚠ 注意：engagement_ratio不再包含在fitness连续计算中
⚠ novelty权重从0.1提升到0.15，robustness从0.25降至0.25（不变），其他权重微调

实际权重分配：w1=0.40, w2=0.20, w3=0.25, w4=0.15（Σ=1.0）
```

**engagement_ratio执行方式（三级阶梯）**：
- engagement_ratio < 0.3 → **淘汰**（直接排除，不进入fitness计算）
- engagement_ratio 0.3-0.5 → **警告**（进入fitness排序，但标注⚠"参与质量待验证"）
- engagement_ratio ≥ 0.5 → **正常**

**相对R1的变更**：
1. engagement_ratio从session_quality的乘法因子变为独立前置过滤器
2. session_quality简化为normalized_session_length（不含engagement_ratio）
3. novelty权重从0.1→0.15
4. robustness权重从0.25→0.20（为novelty让出0.05）

**其他因子定义维持R1不变**：agent_type_agreement、parameter_stability、causal_coherence、exploit_penalty、novelty_bonus

### 4.3 Phase 2 适应度

在Phase 1基础上，根据真人校准数据决定：
- 如果engagement_ratio的构念效度>0.3（与真人自我报告的相关性），则恢复为连续变量参与排序
- 如果构念效度<0.3，则engagement_ratio需要根本性重构（行为签名重新定义）
- 新增multi_session_score、vulnerability_score、cultural_robustness（维持R1方案）
