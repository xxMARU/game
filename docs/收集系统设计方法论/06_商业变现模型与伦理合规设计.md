## 第二章 货币体系设计

### 2.1 多层货币的设计方法论

**标准三层结构：**

| 层级 | 类型 | 获取方式 | 用途 | 案例 |
|------|------|---------|------|------|
| 硬通货 | 高级货币 | 付费购买+少量免费 | 抽卡/高价物品 | 原石(原神) |
| 软通货 | 基础货币 | 游戏内产出 | 日常消耗 | 摩拉(原神) |
| 活动货币 | 限时货币 | 特定活动产出 | 活动商店兑换 | 各类活动代币 |

**多层货币的价值模糊效果：**
- 玩家不直接看到"¥16/抽"，而是看到"160原石/抽"
- 充值时的数字(6480)远大于消耗时的数字(160)——制造"充了很多"的错觉
- FTC已要求公示多层货币的兑换比率——这将成为行业标准

### 2.2 充值档位的锚定设计

**设计原则：**
1. 最低档 ≤ ¥6——破冰价
2. 最高档与核心消费单位不整除——制造"零头"
3. 首充双倍——确保首次体验极佳
4. 各档间提供2-3倍的价格跳跃

**示例（5档结构）：**

| 档位 | 定价(¥) | 获得 | 首充加倍 | 定位 |
|------|---------|------|---------|------|
| 1 | 6 | 60 | 120 | 破冰 |
| 2 | 30 | 300 | 600 | 月卡价位 |
| 3 | 98 | 980 | 1960 | 中等 |
| 4 | 328 | 3280 | 6560 | 高额 |
| 5 | 648 | 6480 | 12960 | 鲸鱼 |

## 第四章 全球监管合规指南

### 4.1 各市场监管要求汇总

| 市场 | 法规/判例 | 核心要求 | 违规后果 |
|------|---------|---------|---------|
| **中国** | 文化部2017年令 | 强制公示所有付费随机内容概率；8岁以下禁付费；未成年月消费限额 | 下架/吊销版号 |
| **日本** | 消费者厅2012年 | 禁止Complete Gacha(集齐兑换)；标准抽卡合法但有行业自律 | 行政处分 |
| **韩国** | 2024年强制执行 | 强制公布所有概率；EA选择关闭FC UT开包而非合规 | 罚款/限制运营 |
| **比利时** | 博彩法认定 | 含可交易物品的付费开箱=赌博，可追究刑责 | 刑事指控 |
| **荷兰** | 2018认定(2022EA上诉翻转) | 可交易战利品箱违法(但判例不稳定) | 罚款€500万 |
| **澳大利亚** | 2024年分级法 | 付费开箱→M级；模拟赌博→R18+ | 限制销售 |
| **美国** | FTC执法(无联邦立法) | COPPA保护+消费者保护法 | FTC罚款(亿级) |

### 4.2 关键FTC判例

#### Epic Games (Fortnite) — $5.2亿和解

| 项目 | 内容 |
|------|------|
| 罚款 | $2.45亿退款 + $2.75亿COPPA罚款 |
| 违规 | 默认开启购买("暗黑模式")；COPPA违规；反直觉按钮布局 |
| 强制要求 | 改变默认隐私设置；增加购买确认步骤；删除非法儿童数据 |

#### HoYoverse (原神) — $2000万和解

| 项目 | 内容 |
|------|------|
| 罚款 | $2000万 |
| 违规 | 多层货币不透明；COPPA违规；"让玩家花数百美元争取几乎没有机会赢得的奖品" |
| 强制要求 | **公示多层虚拟货币兑换比率**；禁止向16岁以下售卖开箱 |

**行业影响：** 这两个判例确立了——多层货币透明度和未成年人保护是不可触碰的监管底线。

### 4.3 合规检查清单(16项)

```
概率与信息
□ 1. 所有付费随机内容的概率是否公示？
□ 2. 概率公示位置是否在购买界面可直接查看？
□ 3. 多层虚拟货币的每环节兑换比率是否公示？
□ 4. 保底规则是否清晰说明？

未成年人保护
□ 5. 是否实施实名认证？
□ 6. 未成年人付费上限是否到位？
□ 7. 16岁以下是否限制付费随机内容？
□ 8. 游戏时长限制是否合规(中国市场)？

消费者保护
□ 9. 购买流程是否有二次确认步骤？
□ 10. 取消/退出按钮是否同等突出(非暗黑模式)？
□ 11. 是否提供消费总额展示(真实货币)？
□ 12. 是否有消费冷却/提醒机制？

市场特定
□ 13. Complete Gacha是否已排除(日本市场)？
□ 14. 可交易付费开箱是否已处理(比利时)？
□ 15. 概率强制公示是否到位(韩国)？
□ 16. 游戏分级是否反映了付费随机内容(澳大利亚)？
```

## 第五章 伦理设计框架

### 5.1 三区设计指南

#### 🔴 红线区(绝对不做)

| 禁止行为 | 法规依据 |
|---------|---------|
| Complete Gacha(集齐解锁) | 日本2012禁令 |
| 向8岁以下出售付费内容 | 中国法规 |
| 未公示概率的付费随机(面向中国/韩国) | 强制法规 |
| 含可交易物品的付费开箱(面向比利时) | 赌博法 |
| 收集13-15岁以下儿童数据未获同意 | COPPA |
| 无确认步骤的一键购买 | FTC判例 |

#### 🟡 灰区(可做但需风控)

| 设计手法 | 风控措施 |
|---------|---------|
| 多层虚拟货币 | 购买界面展示真实货币等价 |
| 限时/稀缺性营销 | 确保倒计时真实，有返场机制 |
| 保底Gacha | 公示概率+规则，天花板合理(≤180抽) |
| FOMO驱动活动 | 确保免费玩家也有有意义的奖励 |

#### 🟢 推荐区(最佳实践)

| 推荐做法 | 预期效果 |
|---------|---------|
| 月卡/通行证为核心变现 | 高付费率+高留存+稳定现金流 |
| 直购+Gacha双轨制 | 让价格敏感用户有确定性选择 |
| 消费健康四层防护 | 降低退款率+合规风险+品牌口碑 |
| 所有概率主动公示 | 超越合规标准，建立信任 |
| 免费玩家体验完整核心循环 | 扩大用户基数→自然转化 |

### 5.2 消费健康四层防护体系

```
第1层：购买确认(每次交易二次确认)
第2层：消费统计(实时显示"本月已消费¥XXX")
第3层：自设上限(玩家可设每月消费提醒)
第4层：冷却提醒(单日消费达阈值时强制提示)
```

## 第六章 反面案例深度复盘

### 6.1 星球大战：前线2 (2017)

**事件时间线：**
- 2017年11月：玩家发现解锁达斯维达需要约40小时游玩或直接付费
- EA社区经理的回复成为Reddit历史上被踩最多的评论(**-68万**)
- 比利时/荷兰介入调查
- EA被迫在发售前夜关闭微交易系统

**商业损失：**
- EA股价下跌约$30亿市值
- 游戏销量低于预期约30%
- 微交易系统被完全重做

**核心教训：** 买断制游戏(¥400+)内置P2W开箱是双重剥削——玩家已经付了全价，再要求付费解锁核心内容是不可接受的。

### 6.2 暗黑破坏神 Immortal (2022)

**争议核心：** 分析师估算完全装备一个角色需要约$100,000或数年免费游玩

**社区反应：**
- Metacritic用户评分：0.2/10
- 核心暗黑系列粉丝社区强烈抵制
- 但商业上——首月收入超$1亿

**教训：** 商业成功≠设计成功。DI证明了即使品牌信誉严重受损，鲸鱼经济仍可短期获利——但长期品牌代价可能远超短期收入。

## 第七章 趋势预判与行动建议

### 7.1 监管趋势

1. **概率公示→全球标准**：中国(2017)→韩国(2024)→FTC判例(2025)，不可逆
2. **未成年人保护是最大风险**：Epic($5.2亿)+HoYoverse($2000万)的罚单将持续升级
3. **多层货币透明度→新焦点**：HoYoverse案首次要求拆解货币链路

### 7.2 商业模型趋势

1. 从纯Gacha向"Gacha+直购"混合模型迁移
2. Battle Pass/月卡成为基础设施
3. 皮肤直购占比将持续提升
4. 降低Gacha收入占比至总收入50%以下

### 7.3 优先行动项

| 优先级 | 行动 | 时间 |
|--------|------|------|
| P0 | 审查16项合规清单 | 立即 |
| P0 | 16岁以下限制付费随机内容 | 立即 |
| P1 | Gacha界面添加真实货币等价展示 | 1个月内 |
| P1 | 消费健康四层防护 | 2个月内 |
| P2 | 建立月卡+通行证+直购三锚点架构 | 版本规划 |
