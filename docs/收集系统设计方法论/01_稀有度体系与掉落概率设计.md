## 第一章 稀有度层级设计方法论

### 1.1 层级数量的选择依据

| 层级数 | 适用场景 | 代表游戏 | 优势 | 劣势 |
|--------|---------|---------|------|------|
| 3层 | 轻度休闲游戏、初期测试 | 早期卡牌游戏 | 认知负荷低，易于理解 | 价值梯度不够细腻 |
| 4层 | 中度游戏、竞技类 | 《炉石传说》(普通/稀有/史诗/传说) | 平衡了丰富度和简洁性 | 中间层易被忽视 |
| 5层 | 主流RPG/收集游戏 | 《原神》(1-5星)、《崩坏：星穹铁道》 | 行业标准，玩家认知惯例最成熟 | — |
| 6-7层 | 重度RPG、长线运营MMO | 《暗黑破坏神4》(普通→传奇→远古→原始远古)、《命运2》 | 为长线运营预留扩展空间 | 底层稀有度存在感极低 |

**设计决策树：**
```
游戏生命周期 ≤ 1年？ → 3-4层
游戏生命周期 1-3年？ → 5层
游戏生命周期 3年+且持续出新内容？ → 5-6层（但初始上线用4-5层，预留扩展位）
```

**核心原则：层级数 = log₂(内容池大小) 的近似值**。内容池100件以内用4层，100-500件用5层，500+件用6层。

### 1.2 各层占比的经验值

**黄金比例参考（5层体系）：**

| 稀有度 | 占比范围 | 推荐基准 | 说明 |
|--------|---------|---------|------|
| 最高（SSR/5★/传说） | 0.5%-3% | 1.5% | 核心欲望目标，驱动付费 |
| 次高（SR/4★/史诗） | 3%-10% | 6% | 有意义的常规奖励，维持参与感 |
| 中等（R/3★/稀有） | 10%-25% | 15% | 填充有用物品 |
| 次低（UC/2★/非普通） | 20%-35% | 30% | 基础材料/资源 |
| 最低（C/1★/普通） | 40%-60% | 47.5% | 保底填充物，回收货币 |

**等比递减公式：** 如果最低层占比为 P₀，公比为 r（通常 r = 0.3-0.5），则第 n 层占比 Pₙ = P₀ × rⁿ。

例如 P₀ = 50%, r = 0.3：50% → 15% → 4.5% → 1.35% → 0.4%，总和约71%，归一化后得到合理分布。

### 1.3 颜色编码系统

**行业通用编码（按稀有度从低到高）：**

| 层级 | 颜色 | 色值参考(Hex) | 备注 |
|------|------|-------------|------|
| 普通 | 白/灰 | #FFFFFF / #9D9D9D | 最无存在感 |
| 非普通 | 绿 | #1EFF00 | 暗黑系列奠基 |
| 稀有 | 蓝 | #0070DD | WoW确立的标准 |
| 史诗 | 紫 | #A335EE | 深紫=高价值已成全球共识 |
| 传说 | 橙/金 | #FF8000 / #FFD700 | 暖色调=最高价值 |
| 超越传说 | 红/彩虹 | #FF0000 / 渐变 | 部分游戏的额外顶层 |

**设计规范：**
- 色盲友好：除颜色外，必须有辅助识别（图标形状、边框样式、星级数字、文字标签）
- 发光强度递增：普通无光 → 传说强烈辉光+粒子特效
- UI一致性：同一稀有度的颜色在所有界面（背包、商店、掉落、聊天）保持完全一致

### 1.4 案例拆解

#### 《原神》稀有度体系

| 星级 | 颜色 | 角色池基础概率 | 综合概率(含保底) | 获取途径 |
|------|------|-------------|----------------|---------|
| 5★ | 金色 | 0.6% | 1.6% | 祈愿（90抽硬保底）、深渊奖励角色 |
| 4★ | 紫色 | 5.1% | 13.0% | 祈愿（10抽保底）、活动、商店兑换 |
| 3★ | 蓝色 | 94.3% | 85.4% | 祈愿（3★武器，回收为星辉/星尘） |

**设计要点分析：**
- 3★物品存在的核心目的不是"奖励"而是"回收货币"——3★武器分解为星尘/星辉，星辉可在商店购买4★角色/武器，形成"垃圾→价值"的转化链路
- 只有5★和4★有角色，3★全部是武器——这保证了"抽到角色"永远是正面体验
- 0.6%的基础概率在行业中属于较低水平（FGO约1%，崩铁0.6%），但1.6%的"综合概率"数字让体系在公示层面显得更慷慨

#### 《暗黑破坏神4》稀有度体系

| 稀有度 | 颜色 | 掉落频率 | 功能定位 |
|--------|------|---------|---------|
| 普通(Normal) | 白 | 极高 | 纯分解材料 |
| 魔法(Magic) | 蓝 | 高 | 低级制作材料 |
| 稀有(Rare) | 黄 | 中 | 中后期制作基础 |
| 传奇(Legendary) | 橙 | 低 | 核心Build构建词缀 |
| 独特(Unique) | 金星 | 极低 | Build定义性物品 |
| 神话(Mythic) | 紫红 | 极极低 | S5新增超稀有层 |

**设计要点分析：**
- 6层体系为长线运营预留了扩展空间——S5新增Mythic层而无需重构整个体系
- 传奇→独特→神话三层高稀有度各有明确功能区分（而非简单数值递增）
- "Smart Loot"系统确保掉落物的职业、部位、词缀与玩家当前Build相关，减少"无用稀有品"的挫败感

#### 《命运2》(Destiny 2)稀有度体系

| 稀有度 | 颜色 | 获取方式 |
|--------|------|---------|
| 普通(Common) | 白 | 早期掉落，后期消失 |
| 非普通(Uncommon) | 绿 | 早期掉落 |
| 稀有(Rare) | 蓝 | 常规掉落 |
| 传说(Legendary) | 紫 | 核心装备，活动/副本掉落 |
| 异域(Exotic) | 金 | 每槽位限装1件，任务/Xûr/掉落 |

**设计要点分析：**
- Exotic的"限装1件"规则将稀有度与游戏机制深度绑定——不是简单的"数值更高"，而是"独特且需取舍"
- Xûr商人每周随机出售不同Exotic，创造了周期性的收集驱动事件
- "坏运气保护"(Bad Luck Protection)和"聚焦解码"(Focused Decoding)让玩家可以定向追求特定装备

## 第二章 掉落概率的数学模型

### 2.1 纯随机模型

**基础公式：**
- 期望抽取次数：E = 1/p（p为单次获取概率）
- 方差：Var = (1-p)/p²
- k次内出货概率：P(X≤k) = 1-(1-p)^k

**示例：** 原神5★基础概率 p=0.006
- 期望值 E = 1/0.006 ≈ 167抽（无保底情况下）
- 50抽内出货概率 = 1-(0.994)^50 ≈ 26%
- 100抽内出货概率 = 1-(0.994)^100 ≈ 45%
- 这意味着如果没有保底，超过一半玩家需要100抽以上——体验极差

**纯随机的致命缺陷：** 方差过大。标准差 σ = √(0.994)/0.006 ≈ 166抽，意味着"运气极差"的玩家可能需要500+抽，而"运气极好"的玩家1抽就出。这种极端体验差异在商业游戏中不可接受。

### 2.2 伪随机分布（PRD）

**原理：** Dota2首创的机制。每次未触发后，下一次的概率递增。连续N次未触发时，触发概率 = C × N（C为初始常数）。

**Dota2 PRD参数表（部分）：**

| 名义概率 | PRD常数C | 最大未触发次数 | 实际期望触发间隔 |
|---------|---------|-------------|----------------|
| 5% | 0.003802 | 约25次 | ~19.5次 |
| 10% | 0.01475 | 约15次 | ~10.0次 |
| 15% | 0.03221 | 约11次 | ~6.7次 |
| 20% | 0.05570 | 约9次 | ~5.0次 |
| 25% | 0.08474 | 约8次 | ~4.0次 |
| 30% | 0.11895 | 约7次 | ~3.3次 |

**PRD的核心优势：** 压缩方差。名义25%触发率下，纯随机可能连续20+次不触发（概率约3%），但PRD在第8次必定触发。

**适用场景：** 实时战斗中的暴击、闪避、触发效果——需要保证竞技公平感的场景。


**期望抽数计算（含软保底）：**

通过逐抽累计计算：
```
expected_pulls ≈ 62.5抽（单次出5★的期望值）
```

**含50/50机制的限定角色期望：**
- 50%概率直接命中UP角色：期望 = 62.5抽
- 50%概率歪（非UP），下次保证UP：期望 = 62.5 × 2 = 125抽
- 综合期望 = 0.5 × 62.5 + 0.5 × 125 = **93.75抽**

- 93.75抽 = 15,000原石
- 6480原石 = ¥648（首充双倍后12,960）
- 期望花费 ≈ ¥750-1000（视是否有首充双倍和活动原石）
- 最坏情况 ≈ ¥1500-2000

### 2.4 收藏家问题（Coupon Collector's Problem）

**问题：** 有N种等概率物品，每次随机获得1种，集齐N种的期望次数是多少？

**公式：** E(T) = N × H(N) ≈ N × (ln(N) + 0.5772)

| 物品种数N | 期望抽取次数 | 期望/N的比值 |
|-----------|------------|------------|
| 5 | 11.4 | 2.3x |
| 10 | 29.3 | 2.9x |
| 20 | 71.9 | 3.6x |
| 50 | 224.6 | 4.5x |
| 100 | 518.7 | 5.2x |

**关键洞察：** 集齐最后几件的期望成本远超前几件。集齐100种物品中最后1种的期望次数 = 100次，而集齐前50种只需约69次。这就是Complete Gacha被日本禁止的数学原因——尾部成本呈对数级增长，玩家在前期形成"快要集齐"的错觉，却在最后阶段面临指数级上升的成本。

**设计启示：** 任何要求玩家"集齐一组"的设计都必须提供碎片合成/定向选择等兜底机制，否则尾部体验必然恶劣。

## 第三章 掉落感知设计

### 3.1 近失效应（Near-Miss Effect）的实现手法

**神经科学基础：** Clark等人(2009, Neuron)发现，近失体验激活与真正获胜相似的大脑奖励回路（纹状体和前岛叶），产生"差一点就赢了"的错觉，驱动继续投入。

**游戏中的具体实现：**

**CS2开箱转盘设计：**
- 转盘展示所有可能物品，高稀有度物品占据极小的扇区
- 指针减速过程中，高稀有度物品频繁从视野划过——玩家看到"差一点就是那把刀"
- 最终停止时指针常"险些"停在高价值物品旁边
- 研究者认定这种设计"在结构和心理上类似于赌博"

**原神抽卡动画时间线拆解：**
- **0-0.5秒**：流星落下，颜色是关键信号（紫色=4★，金色=5★）
- **0.5-1秒**：如果是5★，画面碎裂+全屏金色闪光+独特音效（"叮——"的高频音）
- **1-3秒**：角色/武器剪影渐现，此时玩家已知稀有度但不知具体物品
- **3-5秒**：完整揭露+角色立绘+名字显示
- **5-7秒**：角色展示动画（仅5★有独立展示动画）

**关键设计原则：**
- 稀有度越高，揭示时间越长（3★约1秒，4★约2秒，5★约5-7秒）
- 信息分层揭示：颜色→剪影→完整信息，每层之间制造"期待间隙"
- 批量抽取（十连）中，低稀有度快速跳过，高稀有度时节奏突然放慢

### 3.2 视听反馈的稀有度梯度设计

| 反馈维度 | 低稀有度 | 中稀有度 | 高稀有度 | 最高稀有度 |
|---------|---------|---------|---------|----------|
| 音效 | 轻微提示音 | 明确的提示音 | 独特音乐片段 | 完整的音乐变奏+环境音变化 |
| 视觉特效 | 无/微弱光效 | 彩色光效 | 全屏闪光+粒子 | 画面碎裂+独占动画+镜头语言变化 |
| 动画时长 | ≤1秒 | 1-2秒 | 3-5秒 | 5-10秒 |
| 震动反馈(移动端) | 无 | 轻微 | 中等 | 强烈+多段 |
| UI变化 | 无 | 背景微变 | 背景大幅变化 | UI元素动画+全屏接管 |

### 3.3 设计检查清单

```
□ 稀有度越高，揭示时间越长（低稀有≤1s，最高稀有5-10s）
□ 采用渐进式揭示（颜色线索→轮廓→完整信息）
□ 批量抽取中使用速度变化标识稀有度（加速跳过低稀有，减速展示高稀有）
□ 音效强度与稀有度正相关，最高稀有有独立音乐片段
□ 全屏特效仅用于最高1-2个稀有度层级（避免通胀）
□ 手机端加入差异化震动反馈
□ 近失效应使用需评估当地合规要求
```

## 第四章 价值锚定与定价策略

### 4.1 多层货币体系

**原神的货币链路拆解：**

```
真实货币(¥) → 创世结晶(充值获得) → 原石(1:1兑换+游戏内获取)
                                        ↓
                                   纠缠之缘/相遇之缘(160原石=1个)
                                        ↓
                                     祈愿抽卡
                                        ↓
                                   3★武器 → 星辉/星尘
                                              ↓
                                        商店兑换(月度限购)
```

**每层的价值模糊效果：**
- ¥648 = 6480创世结晶 = 6480原石 = 40.5抽
- 单抽真实成本 = ¥648/40.5 ≈ **¥16/抽**
- 但玩家的心理计算路径是"160原石一抽"——数字大，单位小，模糊了真实价格

**FTC的监管回应：** 2025年FTC判例要求HoYoverse"公示多层虚拟货币各环节兑换比率"——这是里程碑式要求，预计将成为行业标准。

### 4.2 充值档位的锚定设计

**原神充值档位：**

| 充值金额(¥) | 创世结晶 | 首充双倍 | 单结晶成本(¥) | 定位 |
|------------|---------|---------|-------------|------|
| 6 | 60 | 120 | 0.05-0.10 | 破冰（月卡入口价位） |
| 30 | 300 | 600 | 0.05-0.10 | 月卡价位 |
| 68 | 680 | 1360 | 0.05-0.10 | 小额补充 |
| 198 | 1980 | 3960 | 0.05-0.10 | 中等消费 |
| 328 | 3280 | 6560 | 0.05-0.10 | 高额消费 |
| 648 | 6480 | 12960 | 0.05-0.10 | 鲸鱼档位 |

**"零头"定价的心理操作：** 一个5★角色的期望成本约¥750-1000，不整除任何一个充值档位——这意味着玩家几乎总是需要"多充一档"来补齐，充值账户中的"零头"又驱动了下一次消费的心理门槛降低。

## 第五章 合规设计

### 5.1 概率公示的设计规范

**中国法规要求（2017年文化部令）：**
- 必须公示所有虚拟物品的获取概率
- 概率精确到小数点后至少一位
- 公示位置必须在购买界面可直接查看

**原神的合规设计要点：**
1. "综合概率"概念：基础0.6% + 含保底的综合1.6%——合规且传达乐观信号
2. 保底规则用自然语言而非公式——避免数学恐惧，但模糊了软保底细节
3. 概率精确到小数点后三位(0.600%)——传达严谨和透明感

### 5.2 合规检查清单

```
□ 是否公示了所有付费随机内容的概率（面向中国/韩国市场为强制）
□ 是否有保底机制且规则清晰可查
□ 是否展示了多层货币的真实兑换率（FTC判例要求）
□ 未成年人付费限制是否到位
□ 是否有购买确认步骤（非一键购买）
□ 消费提醒/冷却机制是否就绪
```

## 第六章 综合设计建议

### 6.1 概率模型选择矩阵

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 实时战斗触发（暴击/闪避） | PRD伪随机 | 压缩极端序列，保证竞技公平感 |
| 抽卡/扭蛋 | 软保底+硬保底 | 给玩家确定性预期，推动计划性消费 |
| 开放世界掉落 | 加权随机+坏运气保护 | 保持探索新鲜感，避免长时间无收获 |
| 收集/图鉴系统 | 基础随机+碎片合成兜底 | 碎片解决收藏家问题的尾部 |

### 6.2 保底系统参数设计模板

```python
def soft_pity_probability(pull_number, base_rate, soft_pity_start, increment, hard_pity):
    """
    通用软保底概率计算
    - base_rate: 基础概率 (原神: 0.006)
    - soft_pity_start: 软保底起始 (原神: 73)
    - increment: 每抽递增 (原神: 0.06)
    - hard_pity: 硬保底 (原神: 90)
    """
    if pull_number >= hard_pity:
        return 1.0
    elif pull_number > soft_pity_start:
        return min(base_rate + (pull_number - soft_pity_start) * increment, 1.0)
    else:
        return base_rate
```
